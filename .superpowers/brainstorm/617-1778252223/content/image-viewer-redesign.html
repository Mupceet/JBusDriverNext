图片查看器改造方案

三处改动：合并图片列表、底部缩略条、右上角操作按钮

当前：封面和截图分开查看
点击封面 →
onImageClick([cover], 0)
只能看到封面一张
点击截图 →
onImageClick([sample1, sample2, ...], index)
只能看到截图，没有封面
改造后：统一查看
点击封面 →
onImageClick([cover, sample1, sample2, ...], 0)
点击截图 i →
onImageClick([cover, sample1, sample2, ...], i+1)
✓ 封面始终为第一张，点击截图时 startIndex = index + 1

功能说明

封面+截图合并 DetailContent 中预构建 allImages = [cover] + samples，所有图片点击统一传 allImages
底部缩略条 LazyRow 显示缩略图，当前页高亮白边框，点击跳转到对应页，与 pagerState 双向同步
↓ 保存按钮 保存当前图片到相册（MediaStore API + OkHttp 下载 + ContentValues 插入）
↗ 分享按钮 下载图片到临时文件 → Intent.ACTION_SEND + FileProvider → createChooser
